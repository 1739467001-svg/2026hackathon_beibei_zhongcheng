# 🎖️ 3D 坦克飞机大战

> **每一局都是新战场，全场只有你是真人 —— 硝烟、钢铁与翅膀，全在一个网页里。**

![cover](cover.jpg)

不需要下载、不需要注册、不需要显卡驱动 —— 打开浏览器，点一下「开始战斗」，你就在战场中央了。

---

## 🔥 一眼看懂它有多上头

- 🗺️ **每局随机生成地形**：这一局你在丘陵间迂回，下一局就是开阔平原。没有背板，只有应变。
- 🤖 **全员 AI 军团**：友军坦克、友军战机、敌军装甲集群——几十个 AI 单位在战场上自己找目标、自己机动、自己应急修理，你只是其中最关键的变量。
- 🚀 **一键切换座驾**：开局自选 **开坦克** 还是 **开飞机**。
  - 🛡️ **坦克**：装甲厚、能修车，扛得住挨打，适合稳扎稳打。
  - ✈️ **飞机**：风驰电掣、能同时打地面和空中目标——但机身只有一滴血！
- 💥 **拟真的部位伤害系统**（本作最大亮点）：
  - 打中机身，当场坠毁；
  - 打中**机翼**，只掉那一片 —— 掉了机翼的飞机会越滚越偏、越沉越快，**但在坠地之前还能开炮反杀**；
  - 稳稳落地（下沉不急）不会炸，而是趴在地上烧——**烧完之前你还能当固定炮台**。
- 🚫 **无小地图**：只有你眼前看到的东西。听炮声辨方位，看烟柱找敌军——这才是战争。
- ⚠️ **误伤友军会被记帐**：HUD 实时统计你的击毁与友军误伤，别当队内刺客。
- 🎵 **专属主题曲**：主菜单与结算页各配一段原创 BGM（flac 无损），氛围直接拉满。
- 🧭 **瞄准辅助线、弹道下坠、相机震动、履带痕迹、击中反馈**……细节多到数不过来。

## 🎮 操作说明

| 按键 | 坦克 | 飞机 |
| --- | --- | --- |
| `W` / `S` | 前进 / 倒退 | 油门加 / 减 |
| `A` / `D` | 转车体（可原地掉头） | 左右转向 |
| `鼠标` | 自由视角，炮塔跟准星 | 机头跟准星 |
| `←` `→` | 键盘转视角 | 键盘转视角 |
| `↑` `↓` | 调瞄准高低 | 拉杆爬升 / 俯冲 |
| `Q` / `E` | 也能转视角 | 也能转视角 |
| `F` | 切换 移动 / 瞄准 模式 | — |
| `R` | 应急修复（最多修回一半伤害） | — |
| `左键` / `空格` | 按住连发（弹夹 10 发） | 按住连发（一轮 4 发） |
| `M` | 静音 / 恢复音效 | 静音 / 恢复音效 |

**生存法则**：翼尖擦地、擦障碍物、机翼互撞——掉的只是翅膀；机身直接撞上任何东西就完了。飞机比坦克难得多，想稳就先开坦克。

### 📱 手机 / 平板触屏操作

手机上**不需要键盘鼠标**，打开就是完整的触屏操控（竖屏开打会提示你横过来）：

| 触屏手势 | 作用 |
| --- | --- |
| **左半屏按住拖动** | 动态虚拟摇杆：坦克前进 / 倒车 / 转向；飞机上下推 = **爬升 / 俯冲**（自动满油门巡航，专心机动） |
| **右半屏滑动** | 转视角、瞄准 |
| **重力感应钮**（✈️ 飞机专属） | 点一下开启：**倾斜手机 = 压杆**——左右倾转弯、前倾俯冲、后仰爬升，像握着一根真摇杆；再点一下关闭 |
| **开炮钮**（右下大圆钮） | 按住连发 |
| **维修钮** | 应急修复（仅坦克，开飞机时自动隐藏） |
| **移动 / 瞄准 钮** | 切换移动 / 瞄准 模式（仅坦克） |
| **🔊 钮**（左上角） | 静音 / 恢复音效 |

> 💡 重力感应自带**握持校准**：开启那一刻你怎么握着手机，哪就是"水平"；手感方向若不合适，横竖两种握法都会自动适配。iOS 会弹一次权限授权，点允许即可。

移动端还做了这些适配：

- 摇杆是**动态出现**的：拇指按在哪，摇杆底座就落在哪，不用低头找位置；
- 手机自动**降档画质**（分辨率与阴影减半、关抗锯齿），中端机也能流畅跑；
- 竖屏拿着玩会轻轻提示「横屏体验更佳」，横屏时全部 UI 按**刘海屏安全区**（safe-area）避让；
- 菜单、结算、规则面板全部按小屏重排，规则面板里触屏设备会自动显示**触屏操作说明**；
- 想让**真机**（而不是电脑浏览器模拟）玩：双击 `手机联机启动.command`，手机连同一个 Wi-Fi 扫它给出的地址即可。

## 🚀 运行说明（10 秒上手）

游戏使用了 ES 模块，浏览器不允许用 `file://` 直接打开，必须走本地 HTTP 服务。

### 方式一：双击启动（macOS，最简单）

```
双击项目目录里的「启动.command」
```

脚本会自动在 `http://127.0.0.1:5173/` 起一个本地服务（只监听本机），并打开浏览器。

### 方式二：任意 Python / Node 静态服务

```bash
# Python（3.8+）
python3 -m http.server 5173
# 或 Node
npx serve -l 5173
```

然后浏览器打开 `http://127.0.0.1:5173/` 即可。

> 💡 **Safari 用户注意**：macOS 自带的 `python3 -m http.server` 会把 `.flac` 的 MIME 标成 `audio/x-flac`，Safari 对不上就不放音乐。请用上面的「启动.command」（已手动补正 MIME 类型为 `audio/flac`），或改用 Chrome / Edge。

### 方式三：手机真机游玩（同一 Wi-Fi）

```
双击项目目录里的「手机联机启动.command」
```

脚本会对局域网开放服务并打印一个 `http://<电脑IP>:5174/` 地址，手机连同一个 Wi-Fi 直接用浏览器打开，即为触屏操控模式。

**推荐环境**：手机 / 平板用 Safari 或 Chrome；桌面端 Chrome / Edge / Safari 最新版 + 鼠标键盘。

## 📁 项目结构

```
坦克大战/
├── index.html          # 页面入口：菜单、HUD、结算、规则面板
├── 启动.command         # macOS 一键启动脚本（含 MIME 修正）
├── 手机联机启动.command  # 局域网开放，手机真机游玩用
├── cover.jpg           # 封面图
├── menu-theme.flac     # 主菜单 BGM
├── result-theme.flac   # 结算页 BGM
├── src/
│   ├── main.js         # 游戏主循环 / 战斗流程
│   ├── config.js       # 全部数值参数（平衡性调这里）
│   ├── tank.js         # 坦克：移动、炮塔、装甲与维修
│   ├── plane.js        # 飞机：油门、俯仰、部位伤害与坠机
│   ├── ai.js           # 全体 AI 的决策大脑
│   ├── scout.js        # 侦察 / 目标发现
│   ├── bullet.js       # 弹道与命中判定
│   ├── terrain.js      # 随机地形生成
│   ├── camera.js       # 追踪相机
│   ├── hud.js          # 战斗 HUD 与战报信息流
│   ├── effects.js      # 爆炸、烟火等特效
│   ├── tracks.js       # 履带痕迹
│   ├── aimline.js      # 瞄准辅助线
│   ├── audio.js        # BGM 与音效
│   ├── input.js        # 键鼠输入
│   ├── touch.js        # 触屏操控：虚拟摇杆 / 滑屏视角 / 开火按钮
│   └── utils.js        # 通用工具
└── vendor/
    └── three.module.js # Three.js（本地化依赖，离线可玩）
```

**技术栈**：原生 JavaScript + [Three.js](https://threejs.org/)（WebGL），零构建、零框架、零 npm 依赖——克隆下来就能跑。
